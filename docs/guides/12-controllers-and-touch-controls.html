Controllers and on-screen controls

Bluetooth controllers work through XInput. Without one, Madeira draws touch controls you can move and resize.

If it does not work

Game ignores the controller
Try XInput and DirectInput on its Controls page. Some games switch to mouse prompts on any mouse touch; Madeira already ignores stray touches while touch controls are showing.
Wrong buttons
Game details › Controller binds (Keyboard mode) or Edit controls (touch).
