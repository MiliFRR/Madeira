Add a game: stores, copied folders and Battle.net

Steam, Epic, GOG, itch.io and EA games come from their store sign-ins. Anything else you already have as a Windows folder can be added by hand.

1Sign in to a store
Library
Sign in to Steam

Sign in to GOG
Sign in to itch.io
Library: Sign in to Steam / Epic Games / GOG / itch.io / EA app. Games you own then show up to install.
2Copy a game folder

Copy the whole folder, not just the .exe.
In the Files app copy the whole game folder into Madeira › wine › drive_c.
3Tap + and pick the program
Library
+
Other games
My GameAdded
In the library tap +, choose the game’s .exe (or .bat / .cmd). It appears under Other games.
4Battle.net
Battle.net
Advanced ›
Reset to Recommended
Recommended sets the Battle.net lines for you.
Add Battle.net through the Battle.net setup guide in the Madeira releases. Add its Launcher .exe as a game, then tap Reset to Recommended. Keep Madeira in front; first start may stop at the logo: quit and start again.

If it does not work

Game not found after copying
Check the folder is under drive_c and you picked the game’s own .exe, not an installer or launcher stub.
A launcher opens then nothing happens
Open the game’s Launch page and try the Wine desktop (Guide 5), or ask Get Help.
