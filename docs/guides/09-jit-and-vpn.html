JIT and LocalDevVPN: keeping games able to start

iOS only lets Madeira run Windows code while JIT is on. Madeira can enable it with StikDebug or its built-in helper, both using LocalDevVPN.

1Check the status
Settings
JITOff
Memory+On
Enable JIT
Settings shows JIT and Memory+. JIT On (green) means you can play.
2Connect LocalDevVPN
‹ Settings
JIT
LocalDevVPN is installed
Connect with shortcut
Before you play, connect LocalDevVPN. Madeira enables JIT through it.
Open LocalDevVPN and connect. Madeira checks “LocalDevVPN and the Developer Disk Image”. The Connect with … shortcut button can do it for you.
3Choose the method
‹ Settings
JIT
JIT methodAutomatic ›
Run setup again
JIT method: Automatic, Built-in StikJIT or StikDebug. Automatic picks StikDebug if installed. Run setup again walks you through pairing.
4Play starts JIT
Hades
⟳ Starting JIT
If JIT does not come on, you get an error and the game is not started.
Tapping Play turns JIT on itself if needed (the button says Starting JIT), then starts the game.

If it does not work

“Couldn’t Enable JIT”
Connect LocalDevVPN, check the pairing file, then try again. Madeira never silently switches methods.
Free Apple ID: the app stops opening after a week
Signing lasts 7 days. Refresh with the same sideloading app. Settings › Signing: connect LocalDevVPN and Madeira can renew for another 7 days.
“Reset Developer Disk Image”
Last resort button in JIT settings if pairing seems broken. Try it only after reconnecting LocalDevVPN.
