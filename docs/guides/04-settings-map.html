Status at the top

JIT / Memory+
Whether Madeira can run games. JIT must be green. Memory+ depends on how the app was signed.
Enable JIT
Turns JIT on. Play also does it for you.
Free space · Games ready
Storage left and how many games are in the library.

Stores (sign in here)

Steam
Sign in or out, Steam Cloud saves, Madeira Dock, Run setup again.
GOG · itch.io · Epic Games · EA app
Sign in to each store so its games can install and update.

Runtimes

Visual C++ runtimes
Many games need it. Download and install, or remove.
.NET Framework
Wine Mono: Download or Remove.
Web pages in programs
Wine Gecko, for launchers that show web pages.

Playing

Resolution
Default screen size for games (each game can override it).
In games
Touch control button style; landscape when a game starts.
Pointer
Absolute, Relative or Touch, plus touch sensitivity.
Graphics · Display · Memory & sync
Direct3D 9/12 and Vulkan routes, hold the display at its top rate, swap and sync. Leave on defaults unless asked.

Device and storage

JIT
Choose Automatic, Built-in StikJIT or StikDebug. Run setup again lives here.
Signing
Refresh for the 7-day free Apple ID signing.
Saves
Backups and save handling.
External drives
Add a USB or SSD drive or folder, find games on it, remove it.

Help

Diagnostics
Extended logging, Logs (Share Logs, per-game session logs), Send crash reports, All settings.
Appearance
Library cover size, zoom haptics, New look, developer interface.
Credits · Version
Who made what, and the build you are on. Tell us this when you report a problem.

Good to know

Can’t find a setting
Use the search in the Settings tab, or All settings (Diagnostics › All settings): every option by subsystem.
Changes not applying
Some need Madeira restarted. Close it from the app switcher and open it again.
