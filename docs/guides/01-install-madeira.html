Install
The names and layout depend on which sideloading app you use. Any of them works.
Install the IPA with your own Apple ID using SideStore, AltStore, Sideloadly or Plume. A free Apple ID signs the app for 7 days, then it has to be refreshed.
3Open Madeira, choose how to get JIT
JIT setup
JIT lets Madeira run Windows code. Choose how your iPhone gets it.
In-appiOS 27 and later
In-app with pairing file
StikDebug
You can change this later in Settings › JIT.
On first run Madeira asks how your device should get JIT. Automatic uses StikDebug if it is installed, otherwise the built-in helper. On iOS 27 the built-in helper can pair by itself.

If it does not work

Enable JIT says it couldn’t
Open the JIT setup page. Check that LocalDevVPN is connected and that the pairing file is imported. Madeira shows the real error instead of switching methods on its own.
Memory+ shows Off
It depends on how this copy of Madeira was signed. JIT being green is the one that matters for playing; ask in the Madeira Discord if you want more memory.
The app stopped opening after a week
A free Apple ID signs for 7 days. Refresh it with the same sideloading app that installed it. Games and saves are kept.
Built-in JIT says it needs iOS 26
The built-in helper needs iOS 26 or later; the in-app pairing without a computer needs iOS 27. On older iOS use StikDebug.
