Guide 10 · Steam

Steam game stuck on starting, or offline?

A Steam game goes through several short steps before it opens. The message on the starting screen tells you which one you are on.

1The normal steps
Starting
⟳ Signing in to Steam…
Most steps take seconds. Big games can take a minute.
The starting screen says: Starting Madeira Dock… → Loading Steam… → Signing in to Steam… → Waiting for Steam to confirm this game’s license… → The game is starting. Waiting for its window…
2No connection
Starting
⟳ No connection. Asking Steam to sign in offline…
Sign in to Steam while online at least once first (Guide 2).
Offline works if Steam saved your sign-in earlier. You will see “No connection. Asking Steam to sign in offline…” then “Offline: Steam found this game’s license…”
3Account busy
Starting
⟳ Waiting for Steam to end the other session…
“Steam says this account is still playing in another session. Waiting for Steam to end it (up to 3 minutes)…” Close the game on your other device and wait.
4Not enough memory
Not enough memory
Close Madeira, then open it again. The game starts by itself.
Close Madeira
If the screen says Not enough memory it offers Close Madeira. Close it, open Madeira again: the game starts by itself.

If it does not work

Stuck on “Still starting Madeira Dock…”
Wait a minute first; one-time installs run on the first start. If it never ends, use Get Help (Guide 7) and mention the game name.
Stuck waiting for the license
Update to the newest nightly, make sure Steam sign-in is current (Guide 2), then use Get Help.
“Madeira Dock could not complete the Steam launch” with a code
Note the code and use Get Help; the team groups reports by code.
Game opens then closes
See Guide 3: Steam starts and launch arguments.
