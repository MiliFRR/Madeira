If it does not work

Closes as soon as it starts
Set Steam starts to the game’s own program. Tap Steam’s choice again to undo.
Wrong program in the list
The list shows programs in the game’s folder. If the right one is missing, run Verify Game Files or get help (Guide 7).
Arguments do nothing
Check spelling and quotes against what the game or Steam documents. Clear the field to go back to the default.
Still stuck
Guide 7: Get Help sends your short report and answers with a fix you can apply and undo.
