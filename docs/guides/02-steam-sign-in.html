If it does not work

Password rejected
Use the Steam account name (the one you log in with), not the email. Steam reports wrong password, wrong Steam Guard code, rate limit and disabled account as separate errors; wait a few minutes after too many tries.
No Steam Guard prompt
Open the Steam app on your phone and approve there, or use the QR code method.
Game says it needs Valve’s client
Settings › Steam › Madeira Dock. Install it once, then play again.
Game waits for “Steam to confirm this game’s license”
Update to the newest nightly. If it still happens, use Get Help (Guide 7).
