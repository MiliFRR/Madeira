Get Help and Share Logs

When a game stops, Madeira can look at what happened and suggest a fix. Or you can save a log file to post in Discord.

1Game stopped? Tap Get Help
Game stopped
It closed unexpectedly. Get Help looks at what happened and tells you what to try. It takes a few seconds.
Get Help
Not Now
After a game closes unexpectedly Madeira offers Get Help. Say Not Now to skip. Take your time: it takes a few seconds.
2Send Report
Let’s find out why
Madeira sends a short report about this game and gets you an answer in a few seconds.
Send Report
See What’s Sent
See What’s Sent shows the report first. Your name, accounts and personal details are taken out. Your saves, game files and sign-ins are never included.

Not what you saw? Tap what happened and Get Help looks again.
What happened explains it in plain words. Some answers include settings to apply. Tap Apply, play again, and use Undo if it is worse.

If Get Help can’t answer, save a copy for Discord. Or go to Settings › Diagnostics › Logs › Share Logs for one text file (up to 5 MB) with personal details taken out.

If it does not work

I don’t see Get Help
Open the game’s details › Advanced, or Settings › Diagnostics. The Get Help sheet also has a “Still stuck?” area.
It said it can’t answer right now
Tap Save copy for Discord and post the file in the Madeira Discord.
After a fix worked
Say Yes when asked “Did it work?” and Madeira sends the last run’s logs (details removed) so the team learns what fixed it.
Pre-filled settings changed my game
Undo Get Help (game details › Advanced) removes the lines it added.
