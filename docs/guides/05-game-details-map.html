Everyday

Display
Resolution for this game, and MetalFX upscale if you use it.
Controls
Keyboard and mouse, or XInput and DirectInput; touch control opacity and size. Buttons are edited from the in-game menu.
Launch
How the program starts (directly or in the Wine desktop), working folder, and Launch arguments (Guide 3).

When it will not start or runs badly

Steam
Steam starts: pick the game’s own program (Guide 3). Smaller JIT pool. One-time installs.
Compatibility
x87 precision, large memory reservations, the graphics card the game sees (for “no graphics card” errors).
Advanced
Live logs, This game’s config, Share Setup / Apply Shared Setup, Copy Settings, Share Logs, Reset to Recommended, Copy Compat Report.

Store and extras

Steam Cloud · Steam Workshop · Achievements
Saves sync, Workshop items, achievements (Steam games).
Epic Games · GOG · itch.io · EA app
Per-store options, updates and sign-in hints.
Controller binds · Gyro aim & turbo · Mouse
Remap buttons, gyro, pointer behaviour.
Settings files · Mods
Edit the game’s own settings files; mod tools for supported games.
Library details
Title, cover, Home Screen link, where the game lives.

Good to know

The page I want isn’t there
Pages depend on the game and its store. A non-Steam game has no Steam page; Desktop hides pages that name one program.
I changed something and want it back
Advanced › Reset to Recommended (for games that have a Recommended list) puts the game back to the tested settings. Your own lines are replaced.
